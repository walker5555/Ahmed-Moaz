# Walker · Security Field Notes

I work as a SOC analyst with a focus on digital forensics and incident response (DFIR). I investigate suspicious activity on Windows endpoints, starting with the alert and working back through the evidence to establish what ran, when it ran, and what else needs investigation.

## What I do

- **Alert triage and endpoint investigation.** Review process activity, Windows event logs, and endpoint telemetry to put alerts in context and decide where to investigate next.
- **Windows forensic analysis.** Examine disk and memory artifacts, use Prefetch to corroborate program execution, inspect NTFS alternate data streams, and recover historical evidence from Volume Shadow Copies.
- **Detection and reporting.** Cross-check telemetry against forensic evidence when logs are incomplete. Document the timeline, supporting evidence, and gaps so another analyst can follow the investigation.
