# WHO AM I ??

I investigate suspicious activity on Windows endpoints. I use Splunk to correlate Windows event logs and authentication activity, and I review alerts in EDR to understand what ran and which hosts may be affected. I use Cortex XSOAR playbooks to automate routine triage and indicator enrichment.

I’ve gone deeper into digital forensics on real cases, using EDR findings to guide my examination of Windows artifacts. I compare evidence from Prefetch, the Registry, and file system metadata with event logs to reconstruct activity. I use Timesketch to organize the timeline and explain what the evidence supports and where the gaps are.

I’m building my threat hunting skills and use threat intelligence to put forensic findings in context. I compare indicators and observed behavior with known attacker techniques and use those leads to decide which hosts, accounts, or events to check next.
